## Engineering Approach

我習慣將問題拆成 **資料來源 → 資料品質 → 邏輯設計 → 實作 → 測試 → 驗證**，並保留版本與決策紀錄。

在開發過程中，我特別重視：

- **Correctness** — 先確認資料與計算邏輯正確，再進行模型或應用開發
- **Traceability** — 重要資料能追蹤來源、時間與轉換過程
- **Reproducibility** — 分析與模型流程應能重新執行並得到可驗證結果
- **Testing** — 透過測試與 regression verification 降低修改造成的非預期影響
- **Maintainability** — 將大型流程拆分成具有明確責任與契約的模組

我也會使用 AI-assisted development 工具協助研究、程式開發與 Code Review，同時以測試、文件與實際資料驗證產出結果。
